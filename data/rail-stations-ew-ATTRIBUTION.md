# Rail station location data

Placement Atlas uses a filtered England and Wales subset of the **UK Railway Stations** dataset maintained by davwheat, originally compiled from Trainline EU's station database and its listed upstream sources.

- Dataset source: https://github.com/davwheat/uk-railway-stations
- Original upstream: https://github.com/trainline-eu/stations
- Licence: Open Database License (ODbL) 1.0. The full licence is included in this directory as `rail-stations-ew-ODbL.txt`.
- Source attribution is required to davwheat, Trainline EU, and the upstream sources identified in the source repository README.
- `rail-stations-ew.json` is the England and Wales subset used by the application. This machine-readable derivative database is made available under ODbL 1.0.

Station points are local orientation references, not a guarantee of the nearest accessible entrance, live service, walking route, or fastest connection. Placement Atlas labels straight-line proximity separately from route directions.
